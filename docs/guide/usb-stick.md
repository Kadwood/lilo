# Use a USB stick instead

A USB stick always works. Use it when:

- your machine has no Wi-Fi,
- the Wi-Fi is not stable, or
- you are sewing at a place with no network.

## Steps

1. Press **Export**.
2. Choose the **file format** your machine reads. For Brother and Baby Lock, choose **PES**. Read [Choosing a format](export-formats.md).
3. Press **Save**. Pick the USB stick as the place to save.
4. Eject the stick safely. On Mac, drag it to the bin. On Windows, use **Safely Remove Hardware**.
5. Put the stick in the machine and open it from the machine's screen.

## Rules for the stick

- **Put the files at the root.** That means the first screen of the stick, not inside a folder. Many machines do not look in folders.
- **Keep to 12 designs or fewer.** Many home machines show only the first 12 files. If you have more, make a second stick.
- **Use a small stick** formatted FAT32. A very large stick can fail to read.
- **Use plain file names:** letters and numbers, no accents or symbols.

## If the machine does not show the file

- Check the format. The machine only lists formats it can read.
- Check that the file is not in a folder.
- Count the files. Is it more than 12?
- Try another stick.
