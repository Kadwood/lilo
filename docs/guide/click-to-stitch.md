# Click to stitch

**Auto digitize** decides everything for you. **Click to stitch** hands you the controls. Lilo traces the picture into **regions**, the coloured areas. You click the ones you want.

Use it when you want the crest's border as satin, the fabric background left alone, and only the centre filled.

## Steps

1. Open an image. Lilo traces it.
2. Choose the **Click to stitch** tool (press **K**), or press **Click to stitch…** in the left panel.
3. Pick **fill** or **outline** settings in the panel.
4. Click a region to stitch it.
5. To stitch several regions together, **Shift**-click each one, then press **Enter**.
6. Press **Esc** to leave the tool.

Each click is one undo step. Press **⌘Z** if you do not like it.

## Starting from a bare trace

If you already used **Digitize**, use the panel's clear button to remove all stitches. You then start from the bare trace and stitch only what you pick.

## Tips

- Stitch the biggest regions first, then the details on top.
- Choose **outline** for regions thinner than a few millimetres, where a fill would look heavy.
- You can change a stitched region afterwards. Select it and use the left panel. Read [Editing shapes](editing-shapes.md).
