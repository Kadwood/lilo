# Send a design to your machine

Before you send, set up your machine in [Lilo Link](lilo-link-wifi.md).

## Steps

1. Press **Send** at the top right of the editor. It is greyed out until the design has stitches.
2. The **Send to machine** window opens. It says how many stitches and colour changes the file has.
3. Read **Before you sew**. It lists the needle, stabiliser and hooping tips for your fabric.
4. Check the **Machine** list. Pick your machine. Press **Search network** if it is missing.
5. Press **Send**.
6. A progress line shows how many bytes have gone across. When it finishes it says **Sent** and the name the machine stored it under.

Lilo sends a **PES** file, the format Brother and Baby Lock use. The file keeps your thread colours.

## What the warnings at the top mean

The window can list warnings about the design, like stitches that were too long and were split. Read them before you send. Read [What the warnings mean](warnings-explained.md).

## On the machine

The design appears in the machine's memory or its Wi-Fi inbox. The exact place depends on the model, so follow the machine's own manual to open it.

## If a file with the same name exists

Lilo asks you to confirm before it replaces it. Rename the project in the top bar if you want to keep both.

## If it fails

Lilo shows a plain message. Look it up in [Wi-Fi troubleshooting](send-troubleshooting.md).

## Sending from Lilo Link

You can also send from **Lilo Link**, **Machines**, with the **Send** button next to a saved machine. That page also sends an existing file.

## Sending to another make of machine

Use **Export** and save a file for the machine. Read [Choosing a format](export-formats.md) and [USB stick](usb-stick.md).
