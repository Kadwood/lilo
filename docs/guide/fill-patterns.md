# All fill patterns

This page is built from the app's own pattern list, so it always matches what you see in the picker. It has 36 patterns in three families.

- **Rows** are parallel lines of stitches. You can bend them, break them and fade them with a gradient.
- **Motif** patterns repeat a small shape across the area, like a brick or a weave.
- **Path** patterns follow the shape: rings, spirals, rays or flow lines.

Set the pattern in the **Fill pattern** section of the left panel. Each preview there shows the pattern on a 40 by 30 mm shape. Pull compensation, underlay and row spacing work the same for every pattern. Read about them in [Underlay and pull compensation](underlay-and-pull.md).

## Rows patterns (12)

### Tatami

The classic fill: parallel rows with each row's stitches offset from its neighbours.

Supports a gradient. Gets the automatic underlay.

### Original

Parallel rows with a four-step stagger, giving a softer, less regular texture than tatami.

Supports a gradient. Gets the automatic underlay.

### Triangle

Rows that zig-zag in a triangle wave, so stitches form rows of small triangles.

Supports a gradient. Gets the automatic underlay.

### Waves

Smooth wavy rows.

Supports a gradient. Gets the automatic underlay.

| Setting | Range | Default | What it does |
| --- | --- | --- | --- |
| Steps | 2 to 12 | 4 | Needle points per half wave. More steps make smoother curves. |
| Amplitude | 0.2 to 6 | 1 | How far each wave swings sideways, in millimetres. |

### Columns

Rows whose needle points line up, so stitches stack into straight columns.

Supports a gradient. Gets the automatic underlay.

### Offset columns

Like Columns, but every other row is shifted by half a stitch.

Supports a gradient. Gets the automatic underlay.

### Zig-zag

Rows of zig-zag stitches that swing across a band, like a wide satin.

Supports a gradient. Gets the automatic underlay.

| Setting | Range | Default | What it does |
| --- | --- | --- | --- |
| Band width | 0.8 to 8 | 2.5 | How wide each zig-zag band is. |

### Heartbeat

Supports a gradient. Gets the automatic underlay.

| Setting | Range | Default | What it does |
| --- | --- | --- | --- |

### Staircase

### Rainfall

Supports a gradient. Gets the automatic underlay.
