# Projects and autosave

A **project** is your whole design in one file with the ending **.lilo**. It holds your shapes, settings, reference pictures and a small preview image.

## The File menu

The **File** menu in the top-left of the editor has:

- **New design** (**⌘N**)
- **Open…** (**⌘O**), for a .lilo project or a stitch file like PES or DST
- **Save** (**⌘S**)
- **Save As…** (**⇧⌘S**)
- **Revert to saved**, which throws away changes since your last save
- **Version history**
- Open image, Export and Send

## Where files go

The first time you save, Lilo suggests **Documents, then Lilo**. You can save anywhere. Home lists recent projects, newest first, with a thumbnail.

A small dot next to the project name means you have unsaved changes.

## Autosave

Lilo saves a copy of your work every **30 seconds** and when you click away from the window. These copies go into the project's own **version history**, not over your last real save. So autosave never destroys a save you chose to keep.

If Lilo closes by accident, open the project again and look in **Version history**.

## Opening a project

Use **Open…** on Home, **⌘O**, or double-click a .lilo file. Lilo asks before it throws away unsaved changes in the current design.

You can also open a stitch file (PES, DST and others) the same way. It becomes a new, unsaved project. The first **Save** makes a .lilo and never touches the original. Read [Opening files](opening-files.md).

## Name your project

Click the name in the top bar and type. A good name is the job: "JK lining monogram". It also becomes the default file name when you export.
