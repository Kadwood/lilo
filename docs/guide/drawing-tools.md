# Drawing tools

The floating toolbar at the bottom of the canvas holds the tools. Press the key to switch tools. Press **⌘K** to search for any tool by name.

![The toolbar with each tool labelled](screenshots/toolbar.png)

## Moving around

- **Select (S).** Click to select a shape. Drag to move it. Drag on empty space to box-select. **Shift** adds to the selection.
- **Pan (Space).** Drag to move the view. Hold **Space** to pan with any tool.
- **Measure (M).** Drag between two points to read the distance in millimetres. Use it to check a crest against a hoop.

## Drawing shapes

- **Open shape (1).** Click to add points. Right-click or double-click for a curve point. **Enter** finishes. **Esc** cancels. Good for a stem or a border line.
- **Closed shape (2).** Like Open shape, but the outline closes into a fill. Click the first point or press **Enter** to close. Good for a leaf or a badge outline.
- **Circle (3).** Drag a box for an ellipse. Hold **Ctrl** for a perfect circle. Good for a round hat patch.
- **Rectangle (4).** Drag a box. Hold **Ctrl** for a square.
- **Pen (5).** Draw freehand. Lilo smooths the line when you let go. Finish near the start to close it.
- **Satin blocks (6).** Click the left edge, then the right edge, and repeat along the column. **Enter** finishes. You control the exact slant of each stitch block. Good for a curved border or a leaf.
- **Manual stitch (7).** Click to place each stitch exactly where you want the needle. **Enter** finishes. Use it for small touch-ups.

## Words and pictures

- **Text (T).** Click where the text goes, then type in the panel. Read [Lettering](lettering-fonts.md).
- **Click to stitch (K).** Read [Click to stitch](click-to-stitch.md).

## The drawing colour

The coloured dot in the toolbar is the thread your **next** shape will use. Select a shape to change its own colour.

## Undo and redo

**⌘Z** undoes the last step. **⇧⌘Z** redoes it. Sliders merge into one undo step, so one **⌘Z** undoes a whole drag.

## A tip for a round patch

For a 50 mm hat patch, draw a **Circle** and set **Style** to **Outlined**. Choose the **Satin** run type with a width of 3 mm for the border. Then add a filled circle inside. Read [Run types](run-types.md).
